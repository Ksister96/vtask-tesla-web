隐私政策

更新日期：2026-10-22 · 生效日期：2026-10-22 · 适用产品：微特 V-TASK 车控助手（微信小程序及 Web 控制台）

一、我们是谁

「微特 V-TASK 车控助手」（下称"本应用"）是一个独立的特斯拉车辆辅助工具，通过特斯拉官方 Fleet API 为车主提供车辆状态查看与远程控制能力。本应用与 Tesla, Inc. 及特斯拉（中国）无隶属关系。

二、我们收集的信息

  • 登录邮箱：用于创建和识别您的账号、发送登录验证码。我们不收集密码。
  • 特斯拉授权令牌：您完成 Tesla 账号 OAuth 授权后，我们保存用于访问 Fleet API 的访问/刷新令牌。令牌与您的 Tesla 账号绑定，仅用于为您提供本应用功能。
  • 车辆数据：电量、续航、锁定状态、车内/车外温度、位置（仅向您展示行程相关内容时使用）、充电状态等——均来自特斯拉官方接口，仅用于在界面中向您呈现。
  • 指令记录：您通过文字或语音下发的控车指令及其执行结果，用于在界面中向您展示。
  • 语音数据（如您使用语音功能）：按住说话的录音仅用于转写为文字指令，转写完成后音频不保留。

我们不收集您的姓名、身份证号、支付信息，不向任何第三方出售您的数据。

三、信息的使用与存储

  • 上述信息存储于部署者控制的服务器（中国大陆/香港）上，仅用于向您提供本应用功能。
  • 车辆控制指令通过特斯拉官方 Fleet API 及命令接口下发，特斯拉按其自身隐私政策处理相关数据。
  • 您可以随时联系我们删除账号及全部关联数据（见第六条）。

四、信息的共享

除以下情形外，我们不会与任何第三方共享您的信息：

  • 特斯拉公司：车辆数据与控制指令经由特斯拉官方 Fleet API 传输，受特斯拉隐私政策约束；
  • 语音转写服务（如您使用语音输入）：录音仅用于转写为文字指令；
  • 法律法规要求：依法配合有权机关的要求。

五、您的权利

  • 随时在应用内解绑车辆、退出登录；
  • 要求导出或彻底删除您的账号与全部数据；
  • 在特斯拉 App 中随时移除本应用的虚拟钥匙，移除后控车功能立即失效。

六、联系方式

有关本政策或数据处理的任何问题、请求，请通过 GitHub 仓库 Issues 或小程序内反馈入口与我们联系，我们将在 7 个工作日内回复。

七、政策更新

本政策如有实质性变更，我们将在本页面更新并标注日期。重大变更会通过应用内公告提示。
